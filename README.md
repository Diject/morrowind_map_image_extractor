# Morrowind Map Image Extractor
This Morrowind Script Extender (MWSE) mod extracts map tile images from the game and saves them as individual TGA files in a specified directory.

## Configuration
The mod can be configured by editing the `main.lua` file. At the top of the file you will find the settings.

## How to Use
1. Require MWSE.
2. Install the file in any folder inside the `Data Files/MWSE/mods/` directory.
3. Launch Morrowind, load a save game, and press Ctrl+Shift+Y to start the extraction process.
4. When the game crashes, restart the game and repeat step 3.
5. When all images are extracted, a message 'Map tile saving is complete.' will appear in MWSE.log.
